# R05: Evaluate GF/MW detection and small-slip sensitivity

[Task index](../../ROADMAP.md).

## Objective

Quantify GF-only, MW-only and joint localization sensitivity, non-slip responses and computational cost on an explicitly defined independent-truth corpus.
Preserve raw observations and distinguish detection evidence from the final-STEC continuity correction owned by T030.

## Context and authorization

The user authorized default GF/MW processing, offline use of future observations and scientific continuity offsets.
The latest instruction accepts correction solely by final STEC temporal continuity and removes code/noise/integer vetoes.
Accordingly, this evaluation reports responses to genuine TEC steps/ramps and their output errors; it does not require the repair path to preserve an abrupt physical step that the user explicitly asks to align.
Raw phase and ordinary within-segment increments remain traceable.
Natural observations have no external cause labels, so their candidate counts are not treated as accuracy truth.

The historical detector is recoverable from `aac8884:gnss_tec/tec/quality.py`, and the earlier comparison from `d7dbbcb:docs/tasks/R05.md`.
The current finite evaluation and its limitations are in the [completion report](../agents/cycle-slip-validation.md#r05-and-t005-completion-validation).
The [earlier continuity report](../agents/cycle-slip-validation.md#continuity-checkpoint) retains the T030 checkpoint.

## Scope

Native localization/statistics, independent NumPy reference, compact permanent regressions and an offline scientific experiment.
The experiment covers frequency separation/order, cadence, phase/code noise, single/equal/half/GF-cancelling/repeated events, short histories, code transients and physical TEC structures.
Its fixed real cohort retains the original station/day/pair/event identities.

## Implementation Plan

1. Freeze production detector thresholds, native binary and source before performance changes.
2. Compare GF-only, MW-only and joint state rules with independent NumPy statistics over the declared physical matrix and fixed development/held-out seeds.
3. Separate exact-event recall, delayed recall, alarms on smooth no-slip controls, physical-TEC responses and unknown natural edges.
4. Replay paired injected/uninjected real observations and explain inspected misses without station/date/pair-specific rules.
5. Evaluate fixed offline quadratic-step candidates against the complete matrix and retain failed tradeoffs.
   Do not integrate a candidate merely because it recovers an inspected event.
6. Check actual public STEC/VTEC errors and immutable observations, qualify equivalent native/selector implementations with T005, and publish all timing/RSS samples.

## Acceptance Criteria

- [x] GF-only, MW-only and joint variants have independent-truth sensitivity measurements across the declared matrix, including half-cycle and equal/GF-cancelling events.
- [x] Real-data differences, paired-injection accuracy and unknown natural edges have separate denominators and interpretation.
- [x] Raw phase remains immutable; ordinary increments, rapid physical-TEC responses and public STEC/VTEC errors are explicitly checked under the user-selected continuity policy.
- [x] Equivalent optimizations have matching detector/state outputs and measured isolated/full-call cost.
- [x] All seven controlled CIBG timings, the historical resident detection-only <0.1 s outcome, operating limits and candidate decisions are published in the final report.

## Validation

The independent physical generator supplies truth without using production detection or correction helpers.
A separate scalar NumPy implementation verifies detector history, cold starts and reset behavior.
The frozen native binary verifies every output column, dtype, null mask and Float64 value after implementation optimizations.
Actual public-entry controls independently report STEC/VTEC bias, RMS and maximum errors.
Routine pytest uses representative contracts; expanded random evaluation stays in the offline experiment rather than restoring the previous test-count explosion.

## Progress & Handoff

**Delivered evidence:** the complete declared matrix, independent detector arms, fixed real paired cohort, boundary/selector qualification and actual public-output error controls have been evaluated.
No detector threshold was lowered.
The supplemental quadratic-step candidates increased alarms on non-injected controls and are not integrated.
Detailed denominators and failures belong in the [report](../agents/cycle-slip-validation.md#r05-and-t005-completion-validation).

**Known limits:** finite sensitivity remains below perfect recall, especially equal-carrier slips in noisy data.
The four real-cohort misses have no delayed detection and remain reported.
GF/MW candidates do not classify natural ionospheric versus tracking causes.
These measured limits remain visible after this evaluation task closes; externally labeled natural-event assets remain part of T020's broader fixture work.

**Completed:** canonical all-case publication, source/build provenance and final report/metrics are available.
The finite evaluation is complete with its measured limits; future detector-policy work must use new independent evidence rather than reinterpret these failures as successes.
