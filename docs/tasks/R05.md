# R05: Quantify unflagged small-slip sensitivity

[Task index](../../ROADMAP.md).

## Objective

Add 0.5-cycle single-band and simultaneous 1-cycle dual-band cases across cadence/noise regimes; document the detection envelope and evaluate adaptive evidence before lowering thresholds.

## Context

The detection envelope for unflagged small slips needs quantitative definition before threshold changes or sensitivity claims.

## Scope

`gnss_tec/tec/quality.py`, `gnss_tec/tec/constants.py`, `tests/test_cycle_slip.py`.

## Implementation Plan

1. Define a reproducible cadence/noise matrix and synthetic physical controls, including 0.5-cycle single-band, simultaneous 1-cycle dual-band, no-slip noise and rapid genuine TEC changes. Record how ranges and seeds represent the intended inputs.
2. Measure the current detector unchanged; report misses, false positives and retained/rejected samples by regime, using known injected events as independent truth.
3. Evaluate adaptive GF/MW/LLI evidence against the same controls and compare the detection envelope. Treat improved sensitivity without preserving ionospheric changes as a failed tradeoff.
4. Document the supported envelope. Obtain review before changing scientific thresholds/defaults; implement any reviewed change with the same controls and retained raw-phase assertions.

## Acceptance Criteria

- [ ] report misses and false positives while preserving rapid genuine TEC changes; existing 5-cycle cases do not establish half-cycle sensitivity.
- [ ] The report separates unmodified-detector measurements, proposed adaptive evidence and any subsequently validated change; rapid genuine TEC variation remains preserved.

## Validation

Use cycle-slip tests and reproducible synthetic series across the justified matrix; distinguish LLI-flagged and unflagged cases. Report sample/event denominators, missed events and false positives, rather than treating one passing slip fixture as a general sensitivity guarantee.

## Progress & Handoff

**Next:** Specify the cadence/noise matrix and reference controls. Threshold changes require review of the measured tradeoff.
