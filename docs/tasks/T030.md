# T030: Correct cycle slips for scientific TEC continuity

[Task index](../../ROADMAP.md).

## Objective and authorization

Default batch GF/MW localization and correction must make final STEC continuous in time at every localized discontinuity.
The user's latest instruction makes this temporal criterion the sole repair acceptance rule.
It supersedes the earlier integer-uniqueness, code-consistency, physical-step and background-noise vetoes.
Integer identification and externally labeled physical-event recovery are not completion requirements for this continuity task.
R05 still owns detection sensitivity and interpretation of natural events.

Raw observations remain immutable.
Missing or invalid observations remain missing; continuity offsets can align the neighboring valid segments.
Processing is offline and may use up to 32 subsequent epochs.
No station/date/code-name exceptions are permitted.

## Implementation Plan

1. Localize the complete GF/MW and recorded-boundary event mask before estimating offsets.
   Exclude candidate intervals from the normal-rate samples, including adjacent events and a temporary one-epoch excursion.
2. At each event, take the median of the nearest three available non-event rates per side within 32 intervals.
   Interpolate their rates to the event midpoint.
   Use one side when necessary, or zero rate when no ordinary interval exists.
   Subtract the observed increment minus this expected increment cumulatively.
   Uncertainty, code evidence and phase integer metadata cannot veto alignment.
3. Level the corrected phase while keeping bias-product estimates distinct.
   Then align final raw and DCB-corrected STEC independently at localized and bias-reference boundaries.
   Derive VTEC from the aligned calibrated STEC when available.
   This prevents code leveling from reintroducing a signal-switch step without transferring a raw-bias step into an already continuous product.
4. Preserve raw/basic behavior, public QC nulls, physical arc identifiers and traceable per-event phase/raw-STEC/calibrated-STEC offsets.
   Carrier integer fields remain null.
   Share the native path across all entry points and input partitions, with bounded local rate buffers.
5. Replay the fixed previous 99-event real-noise injection cohort, analytic affine/noninteger/adjacent events, shifted noise controls, and complete CIBG output.
   Check final products, signal changes, bias intervals and VTEC mapping.
6. Rebuild and run appropriate regressions and static checks, then measure the complete CIBG path serially: <=1.4 s, peak process RSS <=10^9 bytes.
   Regenerate the canonical benchmark only through its generator.
   Publish current evidence separately from the superseded veto-policy report.
