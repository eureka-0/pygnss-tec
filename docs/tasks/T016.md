# T016: Offer an optional causal Hatch mode

[Task index](../../ROADMAP.md).

## Objective

Define window/time constant, irregular-cadence behavior, reset/warm-up state and code-carrier divergence assumptions.

## Context

A causal Hatch filter has different warm-up/reset and divergence assumptions from offline full-arc leveling. This optional mode must preserve that scientific distinction.

## Scope

new leveling module, `gnss_tec/configuration.py`, tests.

## Implementation Plan

1. Specify window/time constant, irregular-cadence update, warm-up/reset state and code-carrier divergence assumptions using analytic controls.
2. Compare the proposed causal result contract with offline arc leveling and obtain review of scientific defaults/API exposure before implementation.
3. Implement the optional leveling state separately, integrating slips, pair switches, receiver resets and invalid input without rewriting raw phase.
4. Validate analytic ramp, noise, slip and irregular-cadence cases and publish warm-up/divergence limits alongside offline comparisons.

## Acceptance Criteria

- [ ] analytic ramp/noise/slip cases and clear distinction from offline arc leveling.
- [ ] Causal state uses only available past/current observations; reset/warm-up and divergence limitations are visible to users.

## Validation

Use closed-form ramp/noise expectations where applicable and known slip/reset series; vary cadence and missing samples. Check causality and state resets rather than requiring equality with offline leveling.

## Progress & Handoff

**Next:** Define causal-state and analytic validation contracts. No smoothing constant or new default has been selected.
