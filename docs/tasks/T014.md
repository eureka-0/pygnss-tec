# T014: Add IONEX ingestion and comparison utilities

[Task index](../../ROADMAP.md).

## Objective

Preserve epoch, height, exponent, RMS, longitude wrapping and missing cells; align slant/vertical comparisons explicitly.

## Context

A GIM is not local-ray truth; ingestion, interpolation and slant/vertical comparisons need explicit map coordinate/time/height semantics and missing-data handling.

## Scope

new IONEX/product modules, tests, documentation.

## Implementation Plan

1. Select traceable IONEX fixtures and inventory epoch, height, exponent, RMS, grid wrapping and missing-cell representations.
2. Propose a minimal product representation and interpolation/alignment contract, distinguishing slant and vertical comparisons; review material scientific coordinate/interpolation choices before implementation.
3. Implement ingestion and interpolation as separate verifiable steps, retaining original product metadata and missing cells.
4. Validate controlled interpolation/wrapping fixtures and document GIM comparison residuals with provenance and the spatial/temporal limits of interpretation.

## Acceptance Criteria

- [ ] interpolation fixtures and traceable GIM comparisons without treating GIM as local-ray truth.
- [ ] RMS/missing-cell semantics survive ingestion and alignment; GIM comparison documentation explicitly limits local-ray interpretation.

## Validation

Use independent small grids with known interpolation values, longitude wrapping, multiple epochs/heights, exponents and missing cells. Trace every GIM comparison to the source product and alignment assumptions.

## Progress & Handoff

**Next:** Select fixture products and define interpolation/alignment semantics. No IONEX model or comparison conclusion is assumed.
