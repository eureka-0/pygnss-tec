# T018: Standardize export metadata and add Xarray/NetCDF

[Task index](../../ROADMAP.md).

## Objective

Extend existing Parquet support with partitions/QC/provenance; add dimensionally valid Xarray/NetCDF output and optional HDF5 only when needed.

## Context

Parquet support exists; this task extends metadata/partition semantics and adds dimensionally valid scientific interchange. HDF5 remains optional only if a real workflow needs it.

## Scope

`gnss_tec/io/rinex.py`, new export modules, tests.

## Implementation Plan

1. Inventory existing Parquet metadata/round-trip and partition behavior plus user needs for Xarray dimensions and NetCDF serialization.
2. Propose coordinates/dimensions and units/time-scale/QC/calibration/provenance encoding, distinguishing ragged observations from rectangular data. Review public schema and optional-dependency decisions before implementation.
3. Extend Parquet metadata/partitions, then implement Xarray/NetCDF under the reviewed representation; add HDF5 only for a demonstrated need.
4. Verify round-trip values, identities, dtypes where representable, null/missing semantics and all required metadata; document dimensional and format limits.

## Acceptance Criteria

- [ ] units, time scale, coordinates, flags and calibration metadata survive round-trip.
- [ ] Exports retain partitions/QC/provenance without guessing dimension alignment or silently changing coordinate/time semantics.

## Validation

Round-trip representative multi-station/multi-signal, diagnostic and calibrated/relative products through supported formats. Verify metadata as well as numbers; explicitly report format-induced representation limits.

## Progress & Handoff

**Next:** Inventory existing exports and define dimensions/metadata encoding. Format representation and optional dependencies remain unselected.
