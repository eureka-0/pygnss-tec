# R04: Distinguish metadata events from ambiguity resets

[Task index](../../ROADMAP.md).

## Objective

Classify event contents before changing ambiguity state; preserve general events without forcing a reset.

## Context

Metadata-only events and ambiguity resets require different handling. Timed-event cases can be addressed independently of R03's untimed-event representation, while their contracts must agree.

## Scope

`gnss_tec/tec/preparation.py`, `gnss_tec/tec/quality.py`, `tests/test_cycle_slip.py`.

## Implementation Plan

1. Reproduce COMMENT-only flag-4 and non-reset flag-5 cases with continuous phase and the constant-30-TECU/code-noise fixture; inspect the preparation-to-QC state path.
2. Specify an event-content classification that preserves ordinary events and distinguishes receiver/ambiguity resets. Identify how unknown and untimed events are handled without inventing semantics.
3. Obtain review of the reset classification before implementation; replace blanket event-state increments with the reviewed reset evidence and retain original event metadata.
4. Verify non-reset continuity, actual reset splits, pair switches and cross-midnight behavior, and document the classification limits.

## Acceptance Criteria

- [ ] COMMENT-only flag 4 and non-reset flag 5 do not split continuous phase; the constant-30-TECU/code-noise fixture stays at 30 rather than acquiring a 29/31-TECU leveling step, while actual resets still split arcs.
- [ ] Actual receiver/ambiguity resets still produce distinct physical arcs; event retention is not removed to avoid splitting.

## Validation

Use independent physical expectations in cycle-slip and multi-day cases. Compare arc/level identifiers and TEC values: metadata-only events retain continuous phase and 30 TECU; true resets still split. Do not accept a merely lower number of arcs as proof of correctness.

## Progress & Handoff

**Next:** Reproduce the leveling-step cases and draft the event/reset classification for review. Classification and its treatment of unknown events remain unresolved.
