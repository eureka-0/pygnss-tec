# R04: Distinguish metadata events from ambiguity resets

[Task index](../../ROADMAP.md).

## Objective

Classify timestamped event contents before changing ambiguity state; preserve retained general events without forcing a reset.

## Context

Metadata-only events and ambiguity resets require different handling. R03 omits blank-epoch events; this task classifies retained timestamped events. Its timed-event cases can be developed independently.

## Scope

`gnss_tec/calculation/observation_geometry.py`, `gnss_tec/signals/arcs.py`, `tests/test_cycle_slip.py`.

## Implementation Plan

1. Reproduce COMMENT-only flag-4 and non-reset flag-5 cases with continuous phase and the constant-30-TECU/code-noise fixture; inspect the preparation-to-QC state path.
2. Specify a classification for retained timestamped events: flag 1 indicates a power interruption; flags 2/3 describe antenna/site transitions; flag 4 requires inspection of header contents; flag 5 requires its external-event meaning. COMMENT-only flag 4 and non-reset flag 5 must preserve continuity. Keep R01's flag-6 payloads out of observation values. Unknown retained contents need an explicit reviewed policy.
3. Obtain review of the reset classification before implementation; replace blanket event-state increments with the reviewed reset evidence and retain timestamped event metadata. Omitted blank-epoch events must not be assigned to a nearby observation or reintroduced as state changes.
4. Verify non-reset continuity, actual reset splits, pair switches and cross-midnight behavior, and document the classification limits.

## Acceptance Criteria

- [ ] COMMENT-only flag 4 and non-reset flag 5 do not split continuous phase; the constant-30-TECU/code-noise fixture stays at 30 rather than acquiring a 29/31-TECU leveling step, while actual resets still split arcs.
- [ ] Actual receiver/ambiguity resets still produce distinct physical arcs; timestamped event retention is not removed to avoid splitting.

## Validation

Use independent physical expectations in cycle-slip and multi-day cases. Compare arc/level identifiers and TEC values: metadata-only events retain continuous phase and 30 TECU; true resets still split. Do not accept a merely lower number of arcs as proof of correctness.

## Progress & Handoff

**Next:** Reproduce the leveling-step cases and draft the event/reset classification for review. The reset classification and treatment of unknown timestamped events remain unresolved; the blank-epoch omission policy is already fixed by R03.
