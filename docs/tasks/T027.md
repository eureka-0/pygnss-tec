# T027: Make LLI output optional in RINEX observation reads

[Task index](../../ROADMAP.md).

## Objective

Add the keyword-only parameter `include_lli: bool = False` to `read_rinex_obs`. It controls extraction and output of all LLI columns for the selected observations. TEC entry points that read RINEX must explicitly request LLI for their quality control.

## Context

Previously the reader emitted LLI in both layouts. TEC uses the selected phase signals' LLI for loss-of-lock boundaries and half-cycle rejection. The new default is a public output-schema change. LLI contains raw, version-specific bits; this task does not reinterpret them or change scientific QC thresholds.

This delivery also completes [T028's TEC output contract](T028.md) and [T029's NumPy-style docstrings](T029.md). The raw-reader LLI switch controls what is read/emitted; TEC diagnostic selection controls final presentation after QC and calibration. These are separate options.

## Scope

`gnss_tec/rinex/read_rinex.py`, `gnss_tec/_core.pyi`, `src/lib.rs`, `src/observations.rs`, `gnss_tec/tec/tec_calculation.py`, reader/quality tests, `README.md` and `CHANGELOG.md`.

## API Contract

| Setting | Wide output (`pivot=True`) | Long output (`pivot=False`) |
|---|---|---|
| Omitted or `include_lli=False` | No `<code>_lli` columns | No `lli` column |
| `include_lli=True` | LLI companion columns for the selected observation codes | `lli` alongside each selected observation |

“All LLI columns” applies to observations selected by the existing constellation/code filters; it does not pull in unselected signals. There is no per-signal LLI selector. Preserve raw UInt8/null values when enabled. `epoch_flag`, observation values, identifiers, row selection and timestamped event metadata are independent of this switch.

## Implementation Plan

1. Thread `include_lli` through the Python signature, recursive multi-file calls, native `_read_obs` signature and stub. Apply the same default and behavior to both layouts.
2. Gate native LLI extraction, buffers and Arrow column construction in the wide and long paths. Disabling the option must omit those columns at the native boundary, rather than constructing them and dropping them in Python. The upstream RINEX decoder may still parse inline indicator bytes; do not promise reduced source-file I/O or a dependency-level parsing optimization.
3. Make Python projection/schema handling conditional, including empty results and filtered/multi-file inputs. Enabling LLI must preserve existing raw bit values and missing indicators.
4. Make `calc_tec_from_rinex` call `read_rinex_obs(..., include_lli=True)` explicitly. Update internal callers and fixtures that need LLI; verify that changing the raw-reader default does not remove QC information from the RINEX-to-TEC path.
5. Preserve existing acceptance of manually supplied DataFrame/Parquet inputs without LLI. Document that absent LLI supplies no lock/half-cycle information and cannot be reconstructed. Examples that read observations before TEC should explicitly request LLI when full recorded QC is intended.
6. Update the reader docstring in NumPy style and regenerate exact README examples/output together with T028/T029; document both default/schema changes and the `retain_diagnostics` rename in the changelog. Keep source-event flags separate from LLI; R01's flag-6 exclusion must work with either setting.

## Acceptance Criteria

- [x] Default and explicit `False` omit every LLI column; `True` emits all corresponding selected LLI columns in both layouts.
- [x] The native RecordBatch also omits LLI fields/buffers when disabled; the Python API and stub signatures agree.
- [x] Toggling LLI leaves observation values, row keys/counts, code/constellation selection, time handling, `epoch_flag` and retained event metadata unchanged.
- [x] Enabled LLI preserves raw UInt8 values and nulls for supported RINEX 2/3 and compressed inputs; no missing indicator is synthesized as a recorded zero.
- [x] Multi-file, empty and filtered reads honor the parameter consistently.
- [x] RINEX-to-TEC explicitly reads LLI and retains loss-of-lock, half-cycle and signal-switch behavior; existing DataFrame/Parquet missing-LLI behavior is not silently changed.
- [x] Documentation states the default schema change and the explicit opt-in needed by callers that require LLI.
- [x] The same implementation run completes T028/T029 and checks default and diagnostic TEC output with the explicit RINEX LLI opt-in.

## Validation

Test default/False/True across wide/long layouts, filters, multiple files and representative supported compression formats. Inspect native schemas as well as Python output. Compare non-LLI columns exactly and test raw null/bit preservation. Use existing physical QC controls to verify the explicit RINEX-to-TEC opt-in and distinguish disabled output from recorded zero flags.

## Decisions

- Confirmed: the parameter is `include_lli`, keyword-only, with default `False`.
- RINEX-to-TEC explicitly enables LLI; the raw-reader default does not disable its QC.
- Preserve version-specific raw bits. RINEX 2 wavelength-factor interpretation and RINEX 3 half-cycle semantics are distinct; changing their scientific interpretation needs a separate reviewed design.
