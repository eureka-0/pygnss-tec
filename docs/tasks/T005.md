# T005: Explore high-performance arc and GF/MW kernels

[Task index](../../ROADMAP.md).

## Objective

Explore high-performance rolling GF/MW statistics and per-arc state machines, minimizing Python/NumPy/native crossings while preserving the scientific detection envelope validated under [R05](R05.md).

## Context

The current basic arc state machine is already native. Rolling GF/MW detection remains disabled by the user's default-QC decision. R05 records a controlled CIBG baseline: native basic 0.0803 s, Python basic 0.2004 s and Python GF/MW 0.4972 s for the complete TEC call. These timings motivate research into robust native kernels, not immediate restoration of the old detector.

Separate equivalent implementation changes from proposed changes to scientific decision rules. A faster approximation that changes marginal detections requires the accuracy study and review described in R05.

## Scope

`src/selection.rs` or a focused native quality module, `src/lib.rs`, `gnss_tec/_core.pyi`, `gnss_tec/signals/arcs.py`, and the controlled benchmark/scientific fixtures.

## Implementation Plan

1. Profile rolling statistics, state updates, callbacks and conversion/materialization separately using R05's native basic, Python basic and Python GF/MW controls. Include long/high-rate arcs and multi-day/station inputs.
2. Specify ordering, missing-data semantics, prior-only windows, cold starts and resets, raw phase, QC reasons, arc/level boundaries and receiver/event state. Preserve the reference's unit conversions and strict threshold comparisons.
3. Benchmark exact median/MAD on small fixed buffers (10/20 epochs), ring-buffer reuse of phase slopes/MW increments and independent station/PRN parallelism. Remove unused GF MAD work. Avoid repeated per-epoch NumPy arrays, string conversions and Python callbacks. Treat incremental statistics or approximations as candidates to validate, not guaranteed equivalent replacements.
4. Preserve MW-only detection: the measured CIBG events were all MW-only, so gating all MW work behind GF candidates would change the detection envelope. Test equal-carrier and GF-cancelling slips as well as noisy code and genuine TEC variation.
5. Review scientific-state or interface changes before integration. Implement reviewed native candidates in isolated steps, updating type stubs and maintaining Float64 computations and complete arc history across input partitions.
6. Compare all physical outputs and adversarial state transitions before timing. Include boundary conversions and bias validation in complete TEC latency. Explore R05's proposed enabled CIBG TEC-only target below 0.1 s, with one warmup/seven runs and the same engine/threads; report failure to meet it instead of weakening QC.

## Acceptance Criteria

- [ ] Exact candidates preserve the validated reference's detections, reasons, raw phase and physical/bias interval separation; approximate or adaptive candidates receive separate accuracy validation.
- [ ] Measured throughput and memory improve on the justified long/high-rate matrix; full-call comparisons include conversion/materialization and do not reuse completed TEC outputs.
- [ ] MW-only, equal-carrier/GF-cancelling slips, genuine TEC changes, missing values, resets and partition boundaries are covered.
- [ ] All CIBG timings and the enabled 0.1 s target outcome are reported under matched settings, with default-QC decisions kept separate from performance claims.

## Validation

Use R05's independent slip/reset/TEC-change and noise controls with existing multi-day/bias regressions. Compare accepted and diagnostic columns, schema and null masks. Profile before/after on identical inputs, engine/thread settings and pinned builds. Bound retained window state by group/window size and report output-array memory separately.

## Progress & Handoff

**Recorded:** Native basic segmentation exists; controlled robust-detector costs and output effects are in R05.

**Next:** Define the rolling-state contract and compare exact small-window native candidates. Kernel location, integration and default changes remain proposals pending scientific and performance evidence.
