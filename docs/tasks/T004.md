# T004: Introduce genuinely bounded input batches

[Task index](../../ROADMAP.md).

## Objective

Evaluate incremental RINEX decoding before adding RecordBatch streaming; retain cross-batch arc state or use two-pass leveling; partition intermediate Parquet.

## Context

RINEX is fully loaded before returning a LazyFrame; selecting a Polars engine does not establish bounded raw-input memory. Full-arc state and leveling can require information across batches.

## Scope

`src/lib.rs`, `gnss_tec/rinex/read_rinex.py`, `gnss_tec/tec/tec_calculation.py`.

## Implementation Plan

1. Evaluate incremental decoding in the current RINEX/native dependency stack; demonstrate whether decompression/parser inputs can be bounded before promising RecordBatch streaming.
2. Compare cross-batch state retention with two-pass leveling and partitioned intermediate Parquet. Specify physical-arc versus bias/level interval state, receiver events, pair switches and restart boundaries.
3. Submit the input/state/storage architecture for review before implementation. Implement the chosen path in independently testable decoding, state/leveling and partition/export steps.
4. Test batches cutting through slips, resets, bias validity changes and midnight; compare to complete-input reference outputs and measure isolated-process RSS as duration grows.

## Acceptance Criteria

- [ ] bounded peak RSS as duration grows, with no chunk-boundary TEC steps.
- [ ] The memory claim states input/output materialization, retained state and measurement limits; complete scientific arcs survive arbitrary tested chunk boundaries.

## Validation

Use a duration-scaling input matrix with fixed batch settings and matched scientific comparisons. Check complete key/dtype/null/value equivalence and independent constant-TEC/step controls; final collection memory must be distinguished from streaming input memory.

## Progress & Handoff

**Next:** Assess incremental parser feasibility and prepare the state/leveling architecture comparison. Choose the design only after parser feasibility is established.
