# T017: Add ROT/ROTI and qualified scintillation products

[Task index](../../ROADMAP.md).

## Objective

Use same-arc STEC differences, explicit TECU/min, cadence and window coverage; gate S4/sigma-phi behind suitable intensity/high-rate phase inputs and documented detrending.

## Context

ROTI and scintillation claims depend on cadence, coverage, same-arc differences and appropriate observables. Ordinary low-rate RINEX does not by itself support standard S4/sigma-phi claims.

## Scope

new index/QC modules, tests.

## Implementation Plan

1. Specify ROT units (TECU/min), same-arc STEC differencing, window/cadence/coverage and gap/reset behavior; define minimum observable requirements separately for each index.
2. Propose detrending and intensity/high-rate phase requirements for qualified S4/sigma-phi; obtain review of these scientific qualification rules before implementation.
3. Implement ROT/ROTI with independent analytic series, then expose scintillation products only when suitable inputs and detrending are available.
4. Verify insufficient ordinary low-rate inputs are rejected for standard scintillation claims; document qualification, coverage and provenance in outputs.

## Acceptance Criteria

- [ ] reject insufficient ordinary low-rate RINEX inputs for standard scintillation claims.
- [ ] Differences never bridge physical arcs/gaps silently; index units, cadence/window coverage and scintillation input qualification are explicit.

## Validation

Use known linear STEC/rate series, gaps, arc resets and incomplete windows; test low-rate rejection and qualified intensity/phase controls. Separate index numerics from evidence needed for a physical scintillation claim.

## Progress & Handoff

**Next:** Draft the observable/cadence/coverage contract and analytic controls. Qualification and detrending choices require review.
