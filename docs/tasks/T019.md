# T019: Add a CLI that delegates to the library

[Task index](../../ROADMAP.md).

## Objective

Expose read/TEC/QC/export commands with shared configuration, explicit missing-bias policy and meaningful exit codes.

## Context

The CLI is a workflow adapter for existing library behavior, not a second scientific implementation. Shared configuration and missing-bias policy must be reproducible.

## Scope

`pyproject.toml`, new CLI module, `README.md`.

## Implementation Plan

1. Inventory public read/TEC/QC/export entry points, configuration and error semantics; define the minimal CLI command/configuration surface.
2. Propose explicit missing-bias options, meaningful exit codes and a reproducible batch manifest. Review any new public configuration semantics before implementation.
3. Implement thin delegation and entry-point packaging; document actual executable examples without duplicating scientific calculations.
4. Compare CLI/library outputs under identical inputs/configuration and test errors/missing-bias modes, manifest reproduction and installed entry-point behavior.

## Acceptance Criteria

- [ ] CLI/library numerical parity and reproducible batch manifests.
- [ ] The batch manifest records enough inputs/configuration/provenance to repeat the library calculation; CLI defaults do not conceal calibration failures.

## Validation

Use numerical parity for matched library/CLI calls plus missing/unsupported input, QC/export and missing-bias exit cases. Check the installed entry point and re-run documented command examples.

## Progress & Handoff

**Next:** Inventory public entry points and draft the command/manifest contract. CLI configuration and exit-code design need confirmation.
