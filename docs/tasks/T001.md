# T001: Establish stage and memory baselines

[Task index](../../ROADMAP.md).

## Objective

Measure decompression, parsing, navigation, pivot, geometry, QC, leveling, bias and export; record isolated-process peak RSS, input hashes, native build hash and thread counts.

## Context

Production stage timings and isolated-process RSS need consistent measurement boundaries and a representative input matrix.

## Scope

`benchmarks/bench.py`, `benchmarks/benchmark.md`.

## Implementation Plan

1. Inventory available 1 s and 30 s, single/multiple-day and multiple-station inputs; confirm availability/provenance and choose repeatable cases. Record hashes, native build, dependency versions and thread settings.
2. Define non-overlapping stage timing boundaries for decompression, parsing, navigation, pivot, geometry, QC, leveling, bias and export. Keep stage measurements distinct from end-to-end startup/collection cost.
3. Measure with warmups, repeated serial runs and isolated-process peak RSS; document RSS scope/units and scientific comparisons under identical inputs/environment.
4. Publish the matrix and limitations in the existing benchmark report; derive regression budgets only from stable measurements, without converting local suite budgets into production targets.

## Acceptance Criteria

- [ ] repeatable 1/30 s, single/multiple-day and multiple-station cases with scientific comparisons.
- [ ] Each measurement names inputs, build/environment, engine, threads, warmups/repetitions, stage boundaries and RSS definition; scientific identities, dtypes, nulls and numeric residuals accompany timing.

## Validation

Use the existing benchmark harness after checking its current options. Keep repetitions serial for comparable peaks; compare complete accepted outputs and independent scientific residuals. Report unavailable input regimes explicitly instead of substituting smaller cases silently.

## Progress & Handoff

**Next:** Inventory the requested input matrix and agree on timing/RSS boundaries. High-rate/multi-station input availability and production measurements remain unconfirmed.
