# T020: Expand independent scientific regression assets

[Task index](../../ROADMAP.md).

## Objective

Cover poles, leap boundaries, day crossings, signal switches, reset states, storms, mixed cadence and degenerate solvers; document provenance/tolerances.

## Context

New regression assets must cover scientific boundaries using independent expected results and justified tolerances.

## Scope

`tests/`, new reference fixtures, `data/` documentation.

## Implementation Plan

1. Inventory independent fixtures and remaining poles, leap boundaries, day crossings, switches, resets, storms, mixed cadence and degenerate-solver gaps.
2. Select licensed/provenanced observations or independent analytic/reference calculations; justify tolerances and distinguish expected physics from numerical implementation behavior.
3. Add focused assets and tests by scientific contract, retaining full-day/multi-station/all-signal coverage where the assertion requires it.
4. Document fixture provenance/tolerances and run the affected scientific regressions; report reference limits and preserve existing sample/budget meaning.

## Acceptance Criteria

- [ ] expected results are independent of the implementation under test.
- [ ] Each expected result has an independent reference or derivation, provenance and justified tolerance; necessary scientific sample coverage is retained.

## Validation

Audit reference independence and fixture identity, then run affected content-specific tests under the supported versions. Do not regenerate expected truth from the same code path being tested.

## Progress & Handoff

**Next:** Inventory reference coverage and choose independently grounded assets. New fixture sources/tolerances must be justified before addition.
