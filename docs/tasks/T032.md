# T032: Interpret flag-6 events by satellite and phase signal

[Task index](../../ROADMAP.md).

## Objective

Decode retained flag-6 payloads into satellite/phase-specific evidence and restrict their effects to the applicable observation streams when interpretation is reliable. Preserve the original metadata and conservative fallback when scope or meaning is unknown.

## Context

R01 prevents event payload values from overwriting observations. R04 conservatively makes a flag-6 event a station-level reset epoch. It does not decode which PRN or carrier was affected. The RINEX format can report detected or repaired slips, so a recorded number is not automatically an unapplied correction.

T031 supplies the effective version/header field context required when observation-code order or phase conventions change. Static-header fixtures can be prototyped independently, but complete supported-input acceptance must use that effective context.

## Scope

Event parsing in `src/quality.rs`/native ingestion, retained RINEX metadata, `gnss_tec/calculation/observation_geometry.py`, `gnss_tec/signals/arcs.py` and native basic-arc inputs. Coordinate repair-evidence consumption with T030; do not turn event payloads back into normal observations.

## Implementation Plan

1. Review version-specific flag-6 framing and value semantics against the [RINEX specification](https://files.igs.org/pub/data/format/rinex304.pdf), including RINEX 2 satellite lists/continuations and RINEX 3 phase columns. Use T031's effective observation order, units and wavelength context; define blank, zero, malformed, duplicate and unknown records explicitly.
2. Review an internal event model containing epoch/source order, station, satellite, phase-observation identity and raw reported value/meaning. Preserve original event payloads and distinguish known targets from unknown scope. Do not infer that a reported repaired slip should be compensated again.
3. Match reliable evidence to the selected phase pair at the event boundary. A G01/L1 event must not reset G02 merely because the epoch is shared; an event on an unselected phase must follow the reviewed signal-scope policy. Independent receiver/site/power/LLI evidence keeps its normal reset effect.
4. Replace global flag-6 state increments only where the target and interpretation are supported. Keep conservative behavior for incomplete payloads, unknown phase conventions and row-level flags without targeting metadata. Preserve authoritative explicit receiver state, R03 omissions and R01's observation/event separation.
5. Feed interpreted evidence into T030's candidate/consistency checks, not directly into unconditional phase subtraction. Reconcile already-repaired observations and duplicate event/LLI/detector reports so one physical event cannot be applied twice.
6. Validate targeted continuity and fallback, then document event scope, effective-time rules and unsupported cases without implying numerical repair is provided by this parser task alone.

## Acceptance Criteria

- [ ] Supported payloads resolve the intended satellite and phase observation under the effective RINEX 2/3 header; raw observations and event metadata remain intact.
- [ ] Unaffected satellites and independently unaffected selected signals retain continuity; actual targeted slips and independent receiver resets still produce the reviewed behavior.
- [ ] Unknown/malformed scope or standalone flags retain explicit conservative fallback, not silently ignored evidence or an invented target.
- [ ] Header changes, same-time records, compression, multiple files and metadata round trips preserve targeting and Python/native equivalence.
- [ ] Already-repaired and duplicate reports never cause unconditional or double correction; T030 retains ownership of numeric estimation and validation.

## Validation

Construct multi-satellite/multi-signal files where only one phase carries a flag-6 report. Check affected/unaffected arc identities, raw values, derived TEC and event retention. Include active header-order changes, continuations, blanks/zeros, incomplete and conflicting reports, standalone DataFrame flags and already-repaired phase controls. Verify both layouts and LLI settings; never substitute slip payload values for observations.

## Progress & Handoff

**Next:** review the event model against T031's effective-header contract, then prototype static and changing-header fixtures. Precise reported-value semantics and repair-evidence policy remain design decisions; numeric correction is not authorized by successful parsing alone.
