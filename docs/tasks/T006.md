[Task index](../../ROADMAP.md).

## Objective

Check epoch support, matrix rank/conditioning and solver status; center/scale features; precompute MSTD sufficient statistics; return uncertainty and failure reasons.

## Context

MSTD/LSQ estimation needs explicit support, rank, conditioning and failure contracts. Unsupported or failed estimation must not become zero correction.

## Scope

`gnss_tec/calibration/receiver_bias.py`, `tests/test_polars_compat.py`.

## Implementation Plan

1. Inventory current estimator inputs, objective and failure propagation; construct independent known-bias and deliberately degenerate single-SV/constant-mapping controls.
2. Specify epoch/geometry support, rank/conditioning and solver-status checks, plus uncertainty/failure reporting. Assess centering/scaling without changing the fitted scientific model.
3. Review scientific identifiability criteria and any public result-contract change before implementing checks and MSTD sufficient-statistic reuse.
4. Verify identifiable recovery and explicit degenerate failures for both methods; benchmark matched whole-day estimation and document assumptions/limits.

## Acceptance Criteria

- [ ] recover identifiable known biases and reject single-SV/constant-mapping degeneracies.
- [ ] Unsupported or failed estimation retains an uncalibrated/null-TEC meaning; uncertainty and failure reasons are exposed under the reviewed result contract.

## Validation

Use full-day MSTD/LSQ references plus known-bias synthetic systems, single-SV, constant-mapping and insufficient-epoch cases. Inspect solver status, rank/condition behavior, residuals and reported uncertainty; measure speed without weakening physical assertions.
