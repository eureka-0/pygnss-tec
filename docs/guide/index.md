# Documentation

Choose a workflow for reading observations or producing TEC, then check the scientific meaning of the resulting columns.

| Guide | Use it to |
|---|---|
| [RINEX Observations](rinex.md) | Decode observations, filter signals, choose layouts and preserve metadata. |
| [TEC Calculation](tec-calculation.md) | Calculate from RINEX, tables or Parquet; inspect output and execution behavior. |
| [Configuration](configuration.md) | Set signal preferences, geometry, QC, calibration and diagnostic retention. |
| [Scientific Conventions](scientific-conventions.md) | Interpret time, units, calibration, arc state and temporal continuity. |
